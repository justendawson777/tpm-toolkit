## Portfolio Projects Index

This repository contains six specialized sub-projects designed to solve systemic enterprise delivery friction:

### 1. Risks Analyzer (`/Risks Analyzer`)
* **The Problem:** Cross-functional dependencies are buried in silos, leading to reactive, late-stage delivery failures.
* **The Solution:** A Python and Pandas data engine that programmatically parses structured Jira issue schemas. It maps complex workstreams, runs graph-traversal logic to identify multi-hop cascading blocker nodes, and automatically flags high-probability timeline slippages.
* **TPM Focus:** Proactive Risk Mitigation, Algorithmic Critical-Path Modeling, Agile Governance.

### 2. PRD to Jira Converter (`/PRD to Jira`)
* **The Problem:** Translating a Product Requirement Document (PRD) into a clean Jira backlog requires hours of manual ticket creation, often leading to missing requirements or misaligned hierarchies.
* **The Solution:** An automation engine that parses technical product text or structured spec documents, maps the scope directly into the enterprise Agile framework hierarchy (Initiative > Epic > Story), and prepares a seamless, programmatic bulk-import layout.
* **TPM Focus:** Product Vision Alignment, Automated Scoping, Process Streamlining.

### 3. Cloud Cost Auditor (`/Cloud Cost Auditor`)
* **The Problem:** Unoptimized enterprise cloud architectures lead to massive financial inefficiencies and unexpected infrastructure spending.
* **The Solution:** A compliance and resource tracking script that audits active cloud configurations, evaluates allocation footprints, and isolates orphaned assets to drive structural overhead optimization.
* **TPM Focus:** Engineering Cost-Reduction, Resource Optimization, Cloud Infrastructure Management.

### 4. GenAI Evaluation Framework & Model Drift Tracker (`/LLM_Eval_Orch`)
* **The Problem:** Executives face severe hallucination liability and brand damage when engineering teams alter prompts or swap model versions (e.g., legacy to open-source) without objective, standardized metrics, leading to degraded production quality.
* **The Solution:** An automated orchestration pipeline built using optimized token-matrix similarity logic that acts as a CI/CD quality gate to programmatically test LLM responses against a golden dataset for accuracy before deployment, tracking real-time inference telemetry to capture semantic model drift.
* **TPM Focus:** Quality Management, CI/CD Gatekeeping, Production SLA Enforcement, Vendor Risk Management.

### 5. Semantic Vector DB Optimization & Storage Auditor (`/Vector_Db_Optimizer`)
* **The Problem:** Engineering teams rushing to implement Retrieval-Augmented Generation (RAG) are over-indexing and duplicate-chunking enterprise data, triggering exponential, unbudgeted vector database storage bills and severe semantic look-up latency.
* **The Solution:** A technical auditing tool that scans dense embedding indices using flat-memory streaming architecture to discover under-utilized collections, identify highly redundant semantic data embeddings, and enforce enterprise data-tiering to cheaper object storage.
* **TPM Focus:** Storage Cost Optimization (FinOps), Architecture Performance, Enterprise Data Lifecycle Management, RAG Efficiency.

### 6. GenAI Guardrail Proxy (`/llm-gateway-proxy`)
- **The Problem:** Unchecked enterprise LLM and MCP agent traffic exposes organizations to PII leakage, prompt injection, and runaway token spend.
- **The Solution:** A low-latency API gateway proxy enforcing synchronous regex/PII ingress validation gates, token rate-limiting, and asynchronous audit telemetry.
- **TPM Focus:** Shift-Left Security Governance, Latency SLO Management, AI FinOps Controls.
